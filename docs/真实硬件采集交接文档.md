## 1. 当前结论

当前 Pico Logic Analyzer 真实设备已经可以通过串口完成采集，设备确实返回了包含方波跳变的数据。

目前没有证据表明串口连接、采集请求、二进制帧读取或样本解析失败。插件截图中波形看起来接近平线，主要原因是采样率过低、波形在当前时间范围内被压缩，以及当前显示缩放不足。

后续排查重点应放在采样参数和 WebView 显示效果，不应继续优先修改串口解析逻辑。

## 5. 采样率建议

当前设备输出信号周期约为 `1.2 μs`，频率约为 `833 kHz`。`1 MHz` 采样率每个周期只有约 `1.2` 个采样点，不适合观察该方波。

推荐参数：

| 使用场景 | 模式 | 采样率 | Pre Samples | Post Samples |
| --- | --- | ---: | ---: | ---: |
| 日常观察方波 | Edge | `24 MHz` | `100` | `1000` |
| 查看边沿细节 | Edge | `100 MHz` | `100` | `1000` |
| 最高速突发采集 | Blast | `200 MHz` | `0` | `1000` |

Edge 模式建议先使用 `24 MHz`。此时每个周期约有 `29` 个采样点，方波应能正常显示。

Blast 模式必须保持：

- `Pre Samples=0`
- `loopCount=0`
- 采样率使用设备返回的 `blastFrequency`

## 6. 采集链路

VS Code 插件的真实硬件采集链路如下：

```text
Vue WebView
  -> deviceCaptureCommands
  -> WebView postMessage
  -> LACEditorProvider
  -> HardwareDriverManager
  -> LogicAnalyzerDriver
  -> serialport
  -> Pico Logic Analyzer
  -> 二进制采集帧
  -> LogicAnalyzerDriver 解析
  -> CaptureSession
  -> LAC 文件和 WebView 波形渲染
```

关键代码：

- 串口和 Pico 协议驱动：`src/drivers/LogicAnalyzerDriver.ts`
- 扩展宿主消息处理：`src/providers/LACEditorProvider.ts`
- 前端采集命令：`src/frontend/app/composables/deviceCaptureCommands.ts`
- 波形状态：`src/frontend/core/stores/waveformStore.ts`
- 波形绘制：`src/frontend/core/engines/WaveformRenderer.ts`

WebView 不直接访问串口，串口始终由 VS Code 扩展宿主中的 TypeScript/Node.js 驱动完成。

## 7. 已增加的诊断日志

`LogicAnalyzerDriver` 当前会输出以下日志：

```text
[LogicAnalyzer][Capture] 准备读取采集帧
[LogicAnalyzer][Serial] 等待采集帧
[LogicAnalyzer][Serial] 收到采集帧头
[LogicAnalyzer][Serial] 采集帧接收完成
[LogicAnalyzer][Parser] 样本解析完成
[LogicAnalyzer][Capture] 采集完成
[LogicAnalyzer][Channel] 通道样本
[LogicAnalyzer][Capture] 采集失败
```

其中最重要的是：

- `Parser` 的 `transitions`：原始打包样本是否存在跳变
- `Channel` 的 `transitions`：按通道拆分后是否仍存在跳变
- `ones`、`zeros`：通道高低电平分布
- `first32`：前 32 个样本，快速判断是否全 0 或全 1
- `dataLength` 与 `expectedSamples`：设备返回样本数是否与请求一致

判定规则：

| 日志现象 | 结论 |
| --- | --- |
| `Parser transitions=0` | 设备返回数据没有跳变，优先检查采样参数、接线或固件状态 |
| `Parser transitions>0`，但 `Channel transitions=0` | 通道位提取或通道映射有问题 |
| `Channel transitions>0`，界面仍看不到 | WebView 数据传递、文件转换、缩放或渲染问题 |
| `dataLength != expectedSamples` | 采集协议长度或请求参数存在不一致 |
